          Lidhu me GitHub

          Faqja ruhet në GitHub. Që paneli të publikojë ndryshimet, i duhet një “token” që e krijon vetë një herë. Ai ruhet vetëm në këtë pajisje.

          1. Hap krijimin e tokenit në GitHub ↗ (hyr me llogarinë e GitHub).
          2. Te Repository access zgjidh Only select repositories → mist-fragrancehouse.
          3. Te Permissions → Contents zgjidh Read and write (nëse s’është zgjedhur).
          4. Shtyp Generate token, kopjoje dhe ngjite këtu poshtë.
